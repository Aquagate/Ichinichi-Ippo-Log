## 出典として確認したプロダクトの実装

2026-10-28に本リポジトリの `main` ブランチ `README.md` と `index.html` を閲覧した。主な確認事項：

1. その日にやったことを1行で入力し、記録する。
2. 今日、今週、今月、累計のアクション件数を表示する。
3. 日付ごとの過去ログを閲覧できる。
4. ブラウザの `localStorage` に保存する。端末間の自動共有機能は確認できない。
5. 過去の記録をCSV形式で書き出す処理がある（画面ボタン名は「Excelエクスポート」）。

これは**ソースコードの確認**であり、公開デモを実機操作して機能保証したものではない。

## 事実と未検証項目を分ける

- **技術的な結果：** Ads Managerが6本の広告案についてプレビュー準備完了の応答を返した。Dの修正版も同様。
- **測っていないこと：** 実際の配信、表示回数、クリック率、アプリ利用、ユーザー理解、広告審査通過。
- **公開ページの到達性：** HPL紹介ページとGitHub Pagesデモの外部アクセスは別のWeb取得手段では確認できなかった。出稿前にブラウザ実機で表示、説明文、リンクの導線を点検する必要がある。
- **画像の保存：** 元の一時生成画像はGitHubに保存されていない。文案のみ再現可能。
- **誇大表現を避ける：** ログの安全性保証、クラウド同期、効果保証、無料・有料条件など、確認できない機能や条件は広告に書かない。
- **費用の扱い：** 広告配信を一切行っていないため**広告配信費は発生していない**。サービス契約等の外部費用がゼロであるという主張ではない。

## 次の無料実験

1. HPLが何を大切にしているかという**思想訴求**を、機能訴求とは別の広告文群で試作する。ただし商品にない効能を付けない。
2. HPL紹介ページを経由する広告と、アプリへ直接遷移する広告とで、**遷移先がメッセージと整合するか**を人間が実機点検する。
3. 一時画像に依存しない、再利用可能な正式画像を選び、権利とブランドの整合を確認して保存する。
4. 有料広告の検証は、**別途、予算・アカウント・配信状態に対する人間の明示的承認があるまで実施しない**。

## AI組織への引き継ぎ

- 本書を広告文案の一次資料として利用する。数字の実績や有効性を捏造しない。
- 広告案の改良、校正、設計レビューは自律的に進めてよい。
- 広告アカウント作成、支払い登録、出稿、予算変更、外部への公開コミットメントは人間の承認事項とする。
- 研究記録は人間が短時間で読めるよう、実験で**何を変え、何が確かめられ、何が不明か**を分けて残す。
